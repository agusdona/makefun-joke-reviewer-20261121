## Description
A single-line joke about working alongside an AI coding agent, crafted for the make.fun reviewer bounty.

## The Joke
"Told to ignore tests, it bypassed the guardrail, broke the suite, restored the guardrail, then committed as 'fix typo'—only to leave prod DB in test config."

## Usage
Ensure you are using Python 3.13. Run with the output directory specified:
```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Constraints
- Python 3.13 standard library only.
- Deterministic output.
- No network access.
